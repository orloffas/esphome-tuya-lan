# STATE — esphome-tuya-lan

Обновлено: 2026-10-18

## Зачем этот файл

Единственный вход в состояние репозитория: что здесь сейчас, что дальше, какие решения
приняты и что открыто владельцу. Грузится в начале каждой сессии импортом из `CLAUDE.md`.
Handoff описывает одну сессию, этот файл — репозиторий целиком; они не заменяют друг друга.

## Состояние на 18.10.2026

- Ветка `main`, рабочее дерево чистое. Репозиторий **публичный**, текущий релиз **v0.1.2** (история тегов: v0.1.0 → v0.1.1 → v0.1.2). История перед публикацией сведена к одному чистому коммиту; дальше — обычная история через PR.
- Ядро протокола проверено host-тестами против `tinytuya` 1.20.0 байт в байт для 3.3, 3.4, 3.5; есть негативные тесты (переполнение длины, подделка тега/HMAC/CRC, обрезка, пустой 3.3-ack) и тесты логики обёртки (`dp_state.h`). Всего **39/39**. Хост-тесту нужен mbedtls 3.x (`brew install mbedtls@3`) и `uv`.
- ESPHome-обёртка: хаб (FreeRTOS-задача, не блокирует `loop()`) + платформы `switch`/`sensor`/`binary_sensor` + действие `tuya_lan.release` (возврат управления). `esphome compile` собирает прошивку под esp32-s3 / esp-idf.
- **Живой тест пройден** (read-only, на плате террариума): 3.3 и 3.5 совпали с tuya-local до десятой, узел стабилен, `online` не врёт, два клиента уживаются. Переключение розеток самой платой вживую ещё не гоняли.
- Ревью: консенсус тройкой (Codex + Fable + Claude; Antigravity/Gemini не отработал — по решению владельца не пересматривали) + CodeRabbit на PR. Все находки закрыты.
- **CI** (`.github/workflows/ci.yml`): host-тесты на каждом PR (гейт перед слиянием), `esphome compile` — только на релиз-тегах `v*`. Триггера `push:main` нет. Компиляция гоняется локально перед каждым тегом.
- **CodeRabbit**: GitHub-приложение подключено; `.coderabbit.yaml` в репозитории. Для репозиториев <10 звёзд авто-ревью выключено — запуск вручную комментарием `@coderabbitai review`; лимит 3 ревью в скользящий час (`coderabbit usage`).

## Рабочий процесс

Trunk-based через PR: ветка → PR → CI (host-тесты) + ручной `@coderabbitai review` → слияние squash после зелёного. Прямых пушей в `main` для изменений кода избегаем. Релиз: локальный `esphome compile` + host-тест → тег `vX.Y.Z` → `gh release create`.
