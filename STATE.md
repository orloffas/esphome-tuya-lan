# STATE — esphome-tuya-lan

Обновлено: 2026-10-17

## Зачем этот файл

Единственный вход в состояние репозитория: что здесь сейчас, что дальше, какие решения
приняты и что открыто владельцу. Грузится в начале каждой сессии импортом из `CLAUDE.md`.
Handoff описывает одну сессию, этот файл — репозиторий целиком; они не заменяют друг друга.

## Состояние на 17.10.2026

- Ветка `main`. Репозиторий **опубликован**, релиз **v0.1.0**. История сведена к одному чистому коммиту перед публикацией.
- Ядро протокола проверено host-тестами против `tinytuya` 1.20.0 байт в байт для 3.3, 3.4 и 3.5; есть негативные тесты (переполнение длины, подделка тега/HMAC/CRC, обрезанный кадр) и тесты логики обёртки (`dp_state.h`). Всего 35/35.
- ESPHome-обёртка (хаб и платформы `switch`, `sensor`, `binary_sensor`); CI (host-тесты + `esphome compile` под esp32-s3 / esp-idf) зелёный.
- Проведён консенсус-ревью: Codex + Fable + ещё одно Claude-ревью (нога Antigravity/Gemini не отработала — по решению владельца не пересматривали). Все блокеры и HIGH починены и покрыты регрессией.
- **Живой тест пройден:** компонент прогнан на плате террариума в режиме только чтения (2×15 мин) — протокол 3.3 и 3.5 совпал с tuya-local до десятой, узел стабилен, память ровная, `online` не врёт, два клиента на обеих розетках уживаются.
