# STATE — esphome-tuya-lan

Обновлено: 2026-10-17

## Зачем этот файл

Единственный вход в состояние репозитория: что здесь сейчас, что дальше, какие решения
приняты и что открыто владельцу. Грузится в начале каждой сессии импортом из `CLAUDE.md`.
Handoff описывает одну сессию, этот файл — репозиторий целиком; они не заменяют друг друга.

## Состояние на 17.10.2026

- Ветка `main`.
- Ядро протокола готово и проверено host-тестами против `tinytuya` 1.20.0 байт в байт для 3.3, 3.4 и 3.5; есть негативные тесты (переполнение длины, подделка тега/HMAC/CRC, обрезанный кадр).
- ESPHome-обёртка (хаб и платформы `switch`, `sensor`, `binary_sensor`) написана; `esphome compile` собирает прошивку под esp32-s3 / esp-idf без ошибок.
- Проведён консенсус-ревью перед публикацией: Codex и Fable дали находки, плюс ещё одно Claude-ревью. **Нога Antigravity (Gemini) не отработала — кросс-модельный консенсус неполный.** Все блокеры и HIGH починены (переполнение длины кадра, гарантия доставки команды через desired-state, семантика `online_`, проверки создания очередей/задачи, backoff переподключения) и покрыты регрессией.
- Репозиторий ещё не опубликован: ждёт ревью владельцем README и описания репозитория.
